# claude-plugins

Claude Code plugins by David Greer.

```
/plugin marketplace add greer-david/claude-plugins
/plugin install <plugin>@greer-plugins
```

| Plugin | What it does |
|---|---|
| [weekly-roundup](plugins/weekly-roundup/README.md) | Weekly work log from git, GitHub, Claude Code sessions, Jira and Microsoft 365, with Jira updates you approve row by row |
