# Weekly roundup team rules

Shared rules for `/weekly-roundup`. Change them by pull request; the skill never edits this file. Each person's personal rules override these.

**Format:** `- **ID** [team] rule`. IDs are permanent and never reused.

## Epics and tickets

## Wording

- **W1** [team] Findings not yet reviewed are proposed, not confirmed.
- **W2** [team] Open PRs are "open, pending review"; merged PRs are done.
- **W3** [team] Check PR scope with `gh` and name it exactly.
- **W4** [team] Comments post under the author's name and the whole project sees them. Keep them factual.

## Status

- **S1** [team] Never change a status without explicit approval. List status changes, new tickets and merges separately.
- **S2** [team] Don't reopen Completed tickets; comment instead.
