# Weekly roundup rules

**Format:** `- **ID** [team|personal] rule`. IDs are permanent. `[team]` rules are candidates for the shared team rule set; `[personal]` rules stay local. Rules come from your corrections through the learning step.

## Epics and tickets

## Wording

- **W1** [team] Findings not yet reviewed are proposed, not confirmed.
- **W2** [team] Open PRs are "open, pending review"; merged PRs are done.
- **W3** [team] Check PR scope with `gh` and name it exactly.

## Status

- **S1** [team] Never change a status without explicit approval; list status changes separately.
- **S2** [team] Don't reopen Completed tickets; comment instead.
